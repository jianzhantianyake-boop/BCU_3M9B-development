# BCU MATLAB 新手操作入口与教学注释设计

## 目标

为 BCU_3M9B MATLAB 平台提供一个只调度既有实验的单次运行入口、一份面向新手的操作指南，并将项目自有 MATLAB 文件的教学注释统一升级为操作式说明。新增内容不得改变 BCU 方程、默认参数、算法判据、函数签名或 MATPOWER 官方源码。

## 用户工作流

1. 用户在 MATLAB 中打开项目根目录，运行 `run_bcu_beginner.m`。
2. 用户只修改脚本顶部的 `EXPERIMENT_MODE`，然后再次运行该脚本。
3. 控制脚本初始化项目路径，并把执行权交给既有主脚本。
4. 用户根据操作指南，在原始初始化或数值仿真脚本中修改参数；控制脚本不覆盖这些参数、不做批量扫描、不自动保存图片。

## 控制脚本边界

- 新文件必须是脚本而不是函数。原项目多个函数经由 `evalin('base', ...)` 读取 `preset`、`prefault`、`fault`、`postfault` 与 `Basevalue`；函数工作区不能满足这一约束。
- `reduced_cct` 和 `spm_cct` 直接调度对应 CCT 脚本。它们会自行运行静态初始化。
- `reduced_numerical` 与 `spm_numerical` 先运行对应 CCT 脚本，再运行数值仿真脚本，以保证 CUEP 相关能量后处理的工作区依赖已经建立。
- 稳定区域脚本和专用绘图脚本不与 9-bus 主流程混合调度。稳定区域脚本作为探索性独立实验；`Plot_3Dstate.m` 与 `plottmp.m` 仅在指南中列为带数据前提的手动绘图。
- 脚本不得自动关闭用户图窗、清理用户数据、修改原始参数或导出文件。原脚本自身的 `clear` / `close all` 行为只在指南中说明，不被包装器掩盖。

## 新手指南边界

指南必须覆盖：环境准备、首次路径检查、运行顺序、每个实验的入口和输出图、参数修改位置、绘图辅助脚本、常见错误、结果解释限制和 MATLAB 原生验证状态。它必须明确区分：

- 可通过静态代码检查确认的依赖；
- 需要 MATLAB 成功启动后才能确认的原生运行结果；
- Python 平台的独立运行证据，不能替代 MATLAB/Python 严格数值交叉验证。

## 注释改造边界

对每个既有的项目自有 MATLAB 文件，在文件顶部保留原有用途说明，并补全以下中文操作字段：

- 使用方法；
- 参数；
- 返回或工作区结果；
- 步骤；
- 单位；
- 前置条件与常见误用；
- 研究和验证边界。

脚本文件说明运行后在 base workspace 保留的关键结构体和图形；函数文件说明函数签名对应的输入、输出和维度语义。允许补充局部行内教学注释，但不得修改任何可执行代码。

## 验证策略

1. 以只读路径检查确认控制脚本引用的所有既有入口都存在。
2. 检查注释覆盖范围、五个操作字段和文档链接。
3. 复核差异，确认没有改动公式、函数签名或 MATPOWER 官方文件。
4. MATLAB 原生启动、CCT 和数值仿真仍标为 `BLOCKED`，直到本机 settings 插件错误修复并保存新的运行日志。
