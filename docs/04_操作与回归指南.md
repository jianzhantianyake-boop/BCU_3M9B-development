# 04 操作与回归指南

## 两类命令

文档仓库自身的完整性检查与外部 BCU 平台回归分开。前者检查快照、链接和禁止文件；后者
在明确的 `python.exe`、MATLAB 和 MATPOWER 环境中运行模型。

开始前确认：

```powershell
Test-Path 'C:\Users\WangS\AppData\Local\Programs\Python\Python312\python.exe'
Get-Command matlab
```

然后运行 `scripts/audit_environment.ps1`。Python 或 MATLAB 无法启动时必须记为 `BLOCKED`。

## 统一回归

获得解释器执行权限后，以 `-B` 依次运行 v1 smoke、v2 不变量、MATLAB 交叉验证、修复项、
SPM DAE、求解器、P2、配置、CUEP、SPM 联合根审计和八路径报告。推荐使用：

```powershell
.\scripts\run_all_validation.ps1 -PythonExe '<python.exe>' -TimeoutMinutes 30
```

每项输出保存在 `validation/reports/<timestamp>/`（已忽略），并记录实际命令、工作目录、
开始/结束时间、退出码、状态、stdout 和 stderr。超时不自动重试，状态为 `BLOCKED`；崩溃
或断言失败为 `FAILED`。

统一入口在八路径报告之后还会运行阶段 6 的关键方程变异门禁、SPM 参考可比性门禁和
阻尼研究驱动接口测试：

```text
test_mutations.py
test_spm_xval_gate.py
experiments/test_damping_study.py
```

变异测试的通过只说明受控的符号、排序、故障移除、COI 和分支连续性错误能够被捕获，
不等于 `spm_cct` 已通过物理能量门禁。
