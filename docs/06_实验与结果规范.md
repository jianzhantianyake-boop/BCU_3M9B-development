# 06 实验与结果规范

实验结果必须可由代码提交、配置、环境、参考版本和运行日志重生。每个案例至少记录
`case_id`、来源提交、参考版本、故障位置、阻尼设置、CUEP 分支、平衡/网络残差、CCT、
收敛状态、失败原因和运行时间。

失败、未收敛、分支切换和不可比较案例单独列出；禁止用 0、空数组或旧数字填充失败结果。
CSV/JSON manifest、环境审计和精选图存放在被忽略的实验结果目录或另行归档，不将大型
`.mat`、缓存和运行结果提交到 Git。

第一批阻尼研究为 F9/F6 × 总阻尼倍率 0.5/1.0/1.5 × U/G1/G2/G3，共 24 案例。这里的
阻尼映射固定为：`U` 将三个基准阻尼比同时乘以 `gamma`；`G1`、`G2`、`G3` 只将对应
发电机阻尼比乘以 `gamma`，其余保持 0.1。F9 使用 `faultposition=0`，F6 使用
`faultposition=1`。先手动重复 F9、gamma=1.0、U 两次，确认 reduced/SPM 的 SEP、CUEP、
LEA、REA 和标志有效，再建立批量驱动。`experiments/run_damping_study.py` 已实现门禁、
案例顺序和完整 CSV/JSON 字段；当前八路径尚未全部 `MATLAB_XVAL_FULL`，运行只返回
`BLOCKED`，不会初始化求解器、写入零值或生成结果目录。该阶段只能在八路径总门禁通过后启动。

阻尼倍率的数值映射固定为基准阻尼比 `0.1 × gamma`：例如 `gamma=0.5` 时统一阻尼为
`[0.05, 0.05, 0.05]`，`gamma=1.5/G2` 时为 `[0.1, 0.15, 0.1]`。这里的 `gamma`
不是绝对阻尼比；驱动测试会锁定这一接口语义。
