# 02 开发交接

## 入口与模块地图

Python v2 的常用入口是 `run_validation.py`、`run_matlab_xval.py`、`run_full_xval.py` 和
`cli.py`。核心模块分工如下：

- `bcu_v2/spm_energy.py`：SPM 网络代数方程、发电机功率、五项势能和给定临界能量的 CCT；
- `bcu_v2/spm_dae.py`：连续 warm-start 的 SPM 约束流形积分；
- `bcu_v2/cuep.py`：reduced 模型的 type-1 UEP/closest-UEP 搜索；
- v1 `bcu_3m9b/`：案例、网络、约简、动力学和基础数据结构；
- `matlab_platform/B3_MM/`：MATLAB 参考管线，不在本仓库直接改方程。

## 最小安全工作流

1. 运行 `scripts/audit_environment.ps1`，记录解释器、MATLAB、MATPOWER、Git HEAD 和
   本地 `.mat` 情况。
2. 确认工作目录是本仓库，并保存 `git status --short`；不在三个来源仓库中编辑。
3. 新行为先写失败测试，再写最小实现；每个结果带配置、参考版本、容差和状态。
4. 使用 `-B` 运行 Python，避免在源码树新增 `__pycache__`；输出写入被忽略的报告目录。
5. 阶段结束后同时更新代码、测试、验证矩阵和修改日志。

## SPM CUEP 调用链

目标调用链为：严格 SPM fault1 DAE 逃逸点 → MGP 连续网络分支追踪 → 联合发电机/网络平衡求解 →
type-1 分类 → 五项势能 → LEA CCT。Python v2 已实现严格逃逸种子、全网络梯度、MATLAB
同源解析 Newton 校正和可选 Ep4 多段路径积分；但 MGP 射线仍可能长时间运行或在分支折点
失败，未通过物理能量门禁前不能标成自足闭环。网络状态必须是电压幅值而非网络角，所有
Newton/root 初值优先使用上一步状态，失败要返回结构化原因，不能用零值填充。`SpmCuepResult.failure_code`
提供机器可读的终止分类；当前能量门禁失败固定为 `ENERGY_GATE_EXCEEDED`，而不是把它当作
普通崩溃或成功结果。

`spm_potential_energy(..., path_energy_cal=20)` 仅用于复现 MATLAB MGP 射线的 Ep4 路径项；
SPM CUEP 临界能量默认使用 `path_energy_cal=0`，与 `Cal_MM_CCT_SPM.m` 的能量段一致。
`spm_self_contained_cct` 可通过 `max_segments` 设置诊断预算；预算截断只产生未验证状态。

联合平衡的公共速度偏移按阻尼平衡计算：`PCOI=Σ(Pm−Pe)=Σd·omega_coi`，因此实现和
测试都应检查 `Pm−Pe−d·omega_coi`，不能用 `Σm` 代替 `Σd`。

对 MATLAB `Fun_SEPfslove_SPM.m` 的只读方程复现表明，其网络 Q 残差相对于
`Fun_AEfslove_SPM.m` 的物理形式按当前网络电压 `V_i` 做了归一化（包括恒功率负荷项的
`Q/V_i`）。在正电压条件下，两者的零点相同；这不是 `3.3757` 与 `7.5767` 的物理差异
来源。真正的差异来自 `Cal_MM_CCT_SPM.m` 写入 `CUEP_net_theta` 时采用了错误的 COI
平移，后续实现应保持两个事实分开记录。

MATLAB `Fun_Cal_MGP_SPM.m` 中的 `voltage_MGP = theta_iter(no_MGP,:)` 目前只是疑似复制
错误。必须先用只读诊断器确认该分支是否实际执行、退出原因、fsolve 初值和联合残差；在
没有分支执行证据前不得称为已确认 MATLAB 缺陷，也不得修改 MATLAB 文件。

## 变更权限

- 修改 v2：需要失败测试、实现、回归和文档同步；
- 修改 v1：必须先登记缺陷、添加回归测试并得到负责人确认；
- 修改 MATLAB `B3_MM`：本计划禁止；只可新增 `verify/` 导出/诊断器。

## 失败与阻塞

环境无法启动、依赖缺失、MATLAB 参考不可用、求解不收敛、分支跳跃或数据不可比较时，
状态分别写为 `BLOCKED`、`FAILED` 或 `NOT_COMPARABLE`，并记录原因和可复现命令。不得引用
旧日志数字冒充本轮运行。

如需重放有限的 SPM 联合根审计，可在仓库根目录执行：

```powershell
& 'C:\Users\WangS\AppData\Local\Programs\Python\Python312\python.exe' -B `
  python_bcu_v2/run_spm_joint_audit.py --starts 152 --seed 20260902 `
  --seed-file validation/reports/spm_mgp_iterations.json `
  --seed-file validation/reports/spm_mgp_diagnostic.json `
  --output validation/reports/spm_joint_audit_replay_20260902.json
```

`--seed-file` 是可选的只读重放输入：MGP 迭代报告提供有限的角度初值，物理诊断报告
只有在包含校正后的网络角/电压时才提供完整网络种子；存储的混合坐标角不会被当作物理
网络状态。省略该参数时，入口只使用固定随机种子和 SEP 网络 warm-start。报告写入被
忽略的 `validation/reports/`，并记录 `seed_source`、收敛计数和每个根的残差；有限初值
结果不能解释为全根证明。根去重按相对发电机角、网络相对角和电压幅值处理，因此同一
平衡点的 `2π` 周期表示不会被误计为不同物理分支。

若需独立检查 MGP 分支能否连续连接到联合平衡根，可运行：

```powershell
& 'C:\Users\WangS\AppData\Local\Programs\Python\Python312\python.exe' -B `
  python_bcu_v2/run_spm_homotopy_audit.py --steps 100 `
  --output validation/reports/spm_homotopy_audit_latest.json
```

该诊断只读取 MATLAB MGP 报告并逐步 warm-start 网络角/电压，不读取或写入外部
`E_critical`；有限同伦结果不能替代八路径主表中的 MATLAB 交叉验证状态。
