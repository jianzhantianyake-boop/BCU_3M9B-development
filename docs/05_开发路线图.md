状态沿物理轨迹连续；默认案例独立得到物理上可接受的 `E_critical` 且小于严格 SPM

`LEA < REA`；全部既有回归不退化；并先确认
MATLAB MGP 实际退出分支，不逐行盲目移植疑似错误。

当前诊断还发现 MATLAB 紧凑参考的 projected CUEP 网络状态在正确 SPM 网络方程下残差约
`11.3454`。这项证据与 `E_critical=7.57668 > 4.64941` 一起使里程碑保持未完成；在
修正坐标/方程来源并取得独立运行证据前，不得把历史 `3.3757` 或 `0.2053 s` 直接升级为
Python 自足结果。
