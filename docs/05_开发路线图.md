## 当前主里程碑：SPM 参考同坐标化与轨迹闭环

验收必须同时满足：不读取 MATLAB `E_critical`；联合发电机—网络残差小于登记容差；网络
状态沿物理轨迹连续；默认案例独立得到物理上可接受的 `E_critical` 且小于严格 SPM
故障能量峰值（按 MATLAB 同窗 0.5 s 重构约 `5.56767`；直接零占位的 `4.64941` 已废弃）；得到有限 LEA CCT；
`LEA < REA`；全部既有回归不退化；并先确认
MATLAB MGP 实际退出分支，不逐行盲目移植疑似错误。

> 下列关于 `7.57668` 高能量分支和“里程碑未完成”的段落是候选选择器接入前的历史
> 诊断；最新状态以本节后面的“当前里程碑收口”和统一报告为准。

当前诊断还发现 MATLAB 紧凑参考的 projected CUEP 网络状态在正确 SPM 网络方程下残差约
`11.3454`。这项证据与 `E_critical=7.57668 > 5.56767` 一起使里程碑保持未完成；在
修正坐标/方程来源并取得独立运行证据前，不得把历史 `3.3757` 或 `0.2053 s` 直接升级为
Python 自足结果。

最新 MATLAB 只读物理快照已经在实际 CUEP 坐标平移后得到网络残差约 `4.17e-15`，并得到
五项势能合计 `7.57668`。这确认了物理坐标下的 MATLAB/Python 候选是一致的，但并未解决
能量门禁：该值仍超过严格 SPM 故障能量峰值 `5.56767`，因此下一步仍是解释/修正 MGP
分支选择和能量参考，而不是把历史 CCT 数字写回自足接口。

对固定 MATLAB MGP CUEP 发电机角的已知物理网络根进行 501 个随机/扰动初值的有界枚举，
仅复现同一个正电压根（`E_critical=7.576683268`）；这不是“所有 11+ 根”的穷尽证明，
但说明把历史 `3.3757` 直接解释为同一物理分支缺乏支持。后续若要改变控制分支，必须
同时给出 type-1 分类、网络残差、分支连续性和故障能量门禁证据。

进一步对 MATLAB 15 条 MGP 轨迹的 30 个 `update_delta/end_delta` 初值做联合求根审计后，
去重结果仍只有一个满足残差门限的正电压 type-1 根（`E_critical=7.576683268`）；
另一个 type-2 近似点残差约为 `6.8e-2/2.9e-2`，不能作为 CUEP。该有限审计加强了
当前物理门禁结论，但不替代穷尽式全根证明，也不授权把历史混合坐标能量降级为自足结果。
同时，`enumerate_spm_equilibria(grid_points=101)` 的 101×101 reduced 初值网格仍只发现
SEP 和同一个 type-1 根，未发现低能量替代候选；这仍是有限搜索证据。

随后对完整 SPM 发电机—网络联合方程执行 152 个有限初值/扰动启动，覆盖当时登记的 SEP、CUEP、
MGP 更新点、MGP 轨迹末端和随机扰动。去重后只有两个满足严格残差的唯一物理解：SEP
（`E≈0`）与同一个正电压 type-1 CUEP（`E_critical=7.576683267749161`，联合残差约
`3.8e-15`）。没有发现低于严格故障能量峰值的替代分支；这加强了当前门禁结论，但
仍是有限搜索，不是对周期状态空间的全根证明；上述结论只适用于当时登记的 MGP、网格和随机初值范围。

Python 参考门禁现已独立重算并登记 `corrected_raw_e_critical=7.576683268`；其输入是 raw
 fsolve 网络角加回记录的 COI 平移后的物理状态，故只作为可追溯诊断，不替代历史 projected
参考字段；该段文字属于候选选择器接入前的历史状态。

坐标来源已通过 MATLAB 分支执行证据厘清：`postfault.CUEP_net_theta` 使用了未限定的
base 变量 `deltacoi=-0.295690`，而实际 CUEP 平移是 `postfault.deltacoi=-1.997835`；
这解释了 projected 网络残差 `11.3454`。后续实现应显式传递结构字段并增加坐标一致性测试，
但在原 MATLAB 管线未修改前，不能把该修正后的物理快照直接当作历史 CCT 的回归替代。

能量门禁已完成原生双端复核：`matlab_platform/verify/export_spm_energy_series.m` 在
MATLAB R2024a、严格 `PathEnergyCal=0` 和 `tunit=1e-4` 下对 `5000` 个故障轨迹点逐点
计算，得到峰值 `5.567849961155664`（`t=0.2973 s`）；同窗 Python 结果为
`5.5678499591622215`，差约 `2.0e-9`。因此当前 `E_critical=7.5766832677` 超过
真实重算的故障能量峰值并非 Python 采样或网络角展开伪影；在找到满足物理门禁的替代
分支前，主里程碑不能通过。该诊断仅写入被忽略的运行报告，不改动 MATLAB 参考源码。

为增加独立分支证据，已将同伦追踪固化为
`python_bcu_v2/run_spm_homotopy_audit.py`。从 MATLAB MGP 的完整角/网络角/电压状态
开始，100 步同伦在每一步复用上一步网络状态，最终仍收敛到同一个物理 type-1 根：
`E_critical=7.5766832677491305`，网络残差 `1.77e-14`，平衡残差 `7.33e-16`，
没有外部 `E_critical` 输入。该结果强化了“当前登记分支高于严格故障峰值”的历史诊断，
但不宣称全根穷举。
