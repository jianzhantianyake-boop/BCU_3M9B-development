统一汇总措辞：五条路径完成指定输出的 MATLAB 交叉验证；`spm_region` 是一条已完成
平衡点子集对照但尚未覆盖稳定域曲线的部分路径；`spm_cct` 是额外的一条未闭环路径；
`spm_numerical` 当前不可比较。`run_full_xval.py` 的 `5/5` 不等于八条路径全部完成。

本轮执行记录（2026-09-01）：MATLAB R2024a 从本仓库工作目录成功启动并运行
`Cal_MM_CCT_SPM.m`，导出 `spm_cct_v1.json`；观测到 MGP、CUEP 和

当前分支得到的 `E_critical=7.57668` 超过本次 Python 严格 SPM fault-network DAE 计算的

参考，不能替代物理一致坐标结果。统一报告 `validation/reports/full_xval_latest.json` 当前为
`5 MATLAB_XVAL_FULL + 1 UNVERIFIED + 1 NOT_COMPARABLE + 1 UNVERIFIED`；其中五条
FULL 的误差和覆盖范围仍来自历史交叉验证证据，本轮只重新生成并校验了紧凑参考。

阶段 5 收尾记录：MATLAB 已导出固定轨迹检查点（`t=0、0.1、0.2、0.2053、0.21、
0.25、0.3 s`），Python 端已增加端点包含和检查点选择器。修正 SPM 上下文为恒阻抗
网络后，Python 故障/故障后长时 Radau 与 RK45 均可完成，代数残差约 `7.2e-13`；但

与声明工况一致的参考。`spm_region` 的剩余条件是导出并对照 MATLAB 稳定域抽样/边界曲线，
不能用当前两个平衡点替代完整区域覆盖。
