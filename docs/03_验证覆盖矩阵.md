本轮执行记录（2026-09-02）：MATLAB R2024a 从本仓库工作目录成功启动并运行
`Cal_MM_CCT_SPM.m`，导出 `spm_cct_v1.json`；观测到 MGP、CUEP 和
`CCT(LEA)=0.2053 s`。Python 3.12 也已启动并完成参考 schema、SPM 原型和变异测试。
这些运行证明了环境与导出链可用，但不改变 `spm_cct` 的权威状态：Python 自足求解仍因
当前分支得到的 `E_critical=7.57668` 超过本次 Python 严格 SPM fault-network DAE 计算的
故障能量峰值 `5.56767`
而未通过物理门禁。最新只读诊断记录了 MATLAB MGP 输出（约
`[-0.7512, 1.8382, 1.9813]`）和最终 `Results_fsolve`；源码中的
`voltage_MGP = theta_iter(no_MGP,:)` 确实存在，但该次成功结果的电压向量与角度向量不同，
表明最终走的是重复状态更新分支，不能据此认定该行实际执行。紧凑参考同时记录了 MATLAB
raw fsolve 网络角与 projected 网络角，两者最大坐标差约 `1.70`；因此 MATLAB 的
`E_critical=3.3757` 只能作为历史混合坐标参考，不能替代物理一致坐标结果。统一报告
`validation/reports/full_xval_latest.json` 当前为
`7 MATLAB_XVAL_FULL + 1 UNVERIFIED`；其中部分 FULL 的误差和覆盖范围仍来自历史交叉验证
证据，本轮新增并实际重跑了 SPM 数值轨迹和稳定流形固定检查点。

本轮 MGP 实现已改用严格 `fault1` SPM DAE 的点积过零（`tunit=1e-4`）、全网络功率
梯度、MATLAB 同源解析 Newton 和可选 `PathEnergyCal=20` Ep4 射线积分；Ep4 射线采样
与 MATLAB 的逐点误差约 `1e-10`。完整 MGP 外层仍可能需要较长射线搜索，且默认物理
候选未通过 `E_critical < 5.56767` 门禁，因此这些实现证据只更新开发状态，不改变
`spm_cct=UNVERIFIED`。

在修正外层“过大更新”阈值后，Python 15 条 MGP 轨迹进入与 MATLAB 相同的重复状态分支，
最终 MGP 角约为 `[-0.75120823, 1.83824291, 1.98132835]`。该结果证明 MGP 追踪链已
完成同源复现，但联合 CUEP 的物理能量仍为 `7.57668327`，高于严格故障能量峰值，
所以不能据此把 `spm_cct` 升级为完整交叉验证。

追加的 MATLAB 只读物理快照将 raw 网络角减去实际 CUEP 的 COI 平移后，网络残差为
`4.17e-15`，五项势能合计为 `7.57668`，与 Python 自足候选一致。该快照说明此前
`3.3757` 的差异来自坐标/状态取值不一致，而不是可以直接采用的 MATLAB 物理门限；由于
`7.57668 > 5.56767` 的严格故障能量峰值，`spm_cct` 仍保持 `UNVERIFIED`。

坐标诊断已取得分支执行证据：`postfault.deltacoi=-1.997835`，但 MATLAB 写入
`postfault.CUEP_net_theta` 时采用 base workspace 的 `deltacoi=-0.295690`；两者造成的
网络角差约 `4.16939`，正是 projected 参考在正确网络方程下残差约 `11.3454` 的来源。
这是一项已确认的坐标混用现象，但只读诊断没有修改 MATLAB 源码；`voltage_MGP` 疑似复制
行仍按前文规则单独记录，不能与该坐标问题混为一谈。

Python `inspect_spm_cuep_reference` 现对上述物理坐标执行独立能量重算并记录
`corrected_raw_e_critical=7.576683268`（与 MATLAB 只读快照的五项势能合计一致）。该字段
只用于坐标/方程诊断，历史 projected `3.3757` 仍不能作为自足输入或回归目标。

为排除“仅因最终 MGP 初值不佳而错过低能量根”的可能性，本轮又将 MATLAB 15 条轨迹的
全部 `update_delta` 与 `end_delta`（共 30 个初值）分别进行物理网络连续求解和联合
发电机—网络平衡求解。去重后只有两个结果：一个是未达到残差门限的 type-2 近似点
（网络残差约 `6.8e-2`、平衡残差约 `2.9e-2`），另一个是唯一满足残差门限的正电压
type-1 根，其 `E_critical=7.576683268`。这是有限的 MGP 初值审计，不宣称穷尽全部
数学根，但目前没有证据存在同时满足物理残差、type-1 和 `E_critical < 5.56767` 的
替代分支；因此 `spm_cct` 继续保持 `UNVERIFIED`。

作为独立的发电机角候选检查，`enumerate_spm_equilibria(grid_points=101)` 的 101×101
初值网格仍只得到 SEP 与上述同一个 type-1 根；该结果扩大了搜索覆盖范围，但仍不等同
于对周期状态空间的穷尽证明。

在此基础上又对完整 SPM 发电机—网络联合方程执行 152 个有限初值/扰动启动，覆盖已知
SEP/CUEP、MGP 更新点、MGP 轨迹末端和随机扰动。按正电压、联合残差和状态去重后，
只有两个满足严格残差的唯一物理解：SEP（`E≈0`）和同一个 type-1 CUEP
（`E_critical=7.576683267749161`，联合残差约 `3.8e-15`）。没有发现同时满足物理
条件且低于故障能量峰值的替代分支；这是有限搜索证据，不是全根穷举证明，因此
`spm_cct` 仍保持 `UNVERIFIED`。

故障能量峰值又以 `tunit=1e-4`、1001 个输出点复核为 `5.56783827`（约 `t=0.2975 s`），
