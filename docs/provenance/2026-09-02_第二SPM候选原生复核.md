# 2026-09-02 第二个 SPM 候选原生复核

## 目的

此前的 500/152 个有限初值审计主要覆盖 MATLAB MGP 轨迹、其更新点、轨迹末端和
固定随机扰动；它们不能证明周期状态空间没有其他控制分支。为检查这个边界，先用
约简模型的更宽 MOD 初值搜索得到第二个 type-1 候选，再将完整发电机—网络状态交给
MATLAB 原始 SPM 方程重新求解。

## 候选来源

Python `find_type1_ueps(max_group=2, fault_samples=0)` 得到两个约简 type-1 候选：

- 第一候选：`[-0.75855842, 1.85758407, 1.99783545]`，约简势能 `2.11119208`；
- 第二候选：`[1.03254344, -2.63449938, -2.49424800]`，约简势能 `7.94874785`。

原默认 SPM 候选器只取离 SEP 最近的第一候选，因此第二候选此前没有进入完整 SPM
联合求解。

`Cal_MM_Static_SPM` 初始化开始，以第二候选作为 `fsolve` 初值，再调用未修改的
`Fun_SEPfslove_SPM` 和 `Fun_Cal_PotentialEnergy_SPM`。输出：

`2.4e-10`，且网络状态和正电压条件一致。

## 当前判断与后续门禁

这是目前首个同时通过 Python 和 MATLAB 原生物理残差、正电压、type-1 和
`E_critical < fault_energy_peak` 的 SPM 候选，足以推翻此前“已覆盖搜索范围内没有
低能量替代根”的宽泛措辞。但它还不是最终 `spm_cct` 完成证据，因为：

1. 默认 `spm_self_contained_cct` 仍由 MGP 轨迹候选优先，尚未实现多候选筛选；
2. 需要把候选选择规则写成失败优先测试，明确控制分支按物理门禁和能量准则选择；
3. 需要在 MATLAB 同一故障能量扫描中复核该候选的 LEA 交点，并与同一模型的 REA
   或登记的 SPM 时域稳定性判据比较；
4. 在上述门禁完成前，八路径仍保持 `7 MATLAB_XVAL_FULL + 1 UNVERIFIED`，阶段 7
   阻尼研究继续 `BLOCKED`。
