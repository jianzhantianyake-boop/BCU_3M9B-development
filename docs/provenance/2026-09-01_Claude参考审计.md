## 采用的事实与限制

1. 本轮只读 MATLAB SPM 管线实际得到 `E_critical=3.3756797086769623` 和
   `LEA CCT=0.2053 s`，并写入 `validation/references/spm_cct_v1.json`。
2. 本轮 Python 自足求解没有读取上述 `E_critical`；它当前分支的能量门禁失败，报告为
   `UNVERIFIED`，不能用 Claude 日志中的目标数字替代。
3. `Fun_Cal_MGP_SPM.m` 中的 `voltage_MGP=theta_iter(no_MGP,:)` 已由只读诊断器记录为
   “存在且该分支执行过”；在获得分支级修复证据前，仍只称“疑似复制错误”。
4. Claude 材料解释了历史覆盖范围，但不改变本仓库 `SOURCE_MANIFEST.csv` 的来源哈希、
   三个平台提交或权威八路径状态。
5. 本轮进一步用 MATLAB fsolve 原始向量复核了一个坐标问题：raw 网络角加 CUEP 平移后，
   与脚本导出的 projected 网络角最大差约 `1.70`。因此历史 `E_critical=3.3757` 与
   Python 物理一致坐标的 `7.5767` 不可直接比较；这项差异已进入阶段 4 的阻塞诊断。
