# BCU 平台 · 改进与提升路线图

> 定位：`python_bcu/`(v1)冻结为可用基线；本目录 `python_bcu_v2/` 用于承载改进。
> 本文是"怎么把它做得更可信、更能打、更好用"的分级建议，按优先级 P0→P3 排列。

---

## 0. 现状小结

**优点**：核心链路(潮流→Kron 约简→SEP/CUEP→退出点/MGP→能量法 LEA / 时域 REA CCT→
结构保持模型→2D/3D 稳定域)已端到端跑通；8 个实验模式 + 中央控制台；纯 NumPy 可运行。

**已知短板**(排查过程中实测发现，改进的靶子)：
1. `solve_sep` 有**副作用**——会改写 `NetworkState.sep_*`；`run_bcu_experiment` 求 CUEP 时
   污染 `postfault.SEP` → 跨模式共用 `static` 会出错(现靠"各自重建"绕开)。
2. `dynamics.trajectory_stable` 的"末端回到 SEP"判据对**轻阻尼**系统失效(REA≈0)，现用
   有界性判据近似。
3. `find_exitpoint` 在默认故障下退化(退出点 index=0)。
4. SPM 负荷代数解(自写有限差分牛顿)**偶发首步不收敛**——是数值脆弱，非物理失稳。
5. 与 MATLAB 无逐点交叉验证；CUEP 回落时用 MGP 近似；只配了 9 母线 + 两机动态参数。

## P0 — 正确性与可信度(先做，直接决定能否出论文数字)

### P0.1 建立验证套件 `validation/`（不依赖 MATLAB 也能拿可信度）
分层校验，可信度从高到低：
- **T1 物理/数学不变量**：潮流功率失配→0；SEP 是真平衡点(RHS→0、雅可比全稳定)；
  CUEP 为 type-1(梯度=0、恰一个非负特征值、`V(CUEP)>V(SEP)`)；无阻尼能量守恒、
  有阻尼单调不增；**CCT 夹逼 `LEA ≤ 真值 ≤ REA`**；零故障必稳、极长故障必失稳、
  CCT 对故障严重程度单调；步长/网格细化收敛(RK4 约 4 阶)。
- **T2 独立参照**：单机无穷大 + **等面积准则闭式 CCT**(金标准)；轨迹 vs `scipy.solve_ivp`；
  潮流 vs MATPOWER/`PYPOWER`；教科书 9 母线基准值(数字由你提供，不臆造)。
- **T3 MATLAB 差分**：逐层比对，标注为"忠实复现/回归"，**非**正确性判据。

### P0.2 修 5 个已知隐患
- `solve_sep` 去副作用：不写回 state，返回新的 SEP 对象(或显式 `inplace=False`)。
- 统一稳定性判据：可配置"有界性 / 回到 SEP(需足够长仿真)"，默认用稳健的有界性。
- 修 `find_exitpoint` 退化(检查点积过零判据与初值)。
- SPM 代数解稳健化(见 P1.1)。
- `run_bcu_experiment` 不污染输入 `static`(深拷贝 postfault 再求 CUEP)。

## P1 — 数值方法与求解器(稳健性 + 精度的最大杠杆)

> v1 刻意"纯 NumPy 无 SciPy"。但 SciPy 已装，升级收益极大。

### P1.1 引入 SciPy 求解器(向后兼容，可开关)
- 非线性方程(SEP/CUEP/SPM 代数)：用 `scipy.optimize.root`(hybr/lm)替自写牛顿，
  更稳、更快、自带收敛诊断。**解析雅可比**替有限差分(潮流/SEP 都能推)，再提一档。
- 时域积分：`scipy.integrate.solve_ivp`(RK45/DOP853/Radau)带**自适应步长**与**事件检测**。

### P1.2 事件驱动的精确 CCT
用 solve_ivp 的 event 精确定位"退出点/失步时刻"，再对切除时刻做**二分搜索**(bisection)，
比现在的固定网格 REA 精确 1~2 个数量级，且快。

### P1.3 严格 DAE 的 SPM
用带质量矩阵的隐式积分器(`Radau`/`BDF`)真正解结构保持 DAE，替换现在"故障段约简+
故障后正向 SPM"的近似，向 MATLAB `ode15s` 对齐。

## P2 — 建模能力扩展(决定"能研究什么系统")

### P2.1 通用系统装配层
- 任意 MATPOWER case + 每机动态参数的装配器；把 39 母线 10 机动态参数配全。
- 故障库:多故障位置/多线路/时序故障，配置化描述。

### P2.2 发电机模型分级(可选精度)
经典(现有) → 单轴(含 `E'q` 动态) → 含 AVR/励磁 → 含调速器/PSS。分级开关，能量函数
方法随模型阶数扩展。

### P2.3 负荷与器件
真正的 ZIP/频率相关/动态负荷(现仅恒阻抗)；感应电机负荷。

### P2.4 变流器/新能源(IBR)——真正的前沿
GFL(PLL + 电流环)与 GFM(下垂 / VSG)模型。**注意**：v1 的"GFL"只是经典两机换参数，
不是真 IBR。这块是独立的大工作，也是最有研究价值的方向(变流器主导电网暂态同步稳定)。

## P3 — 方法学深化 与 软件工程质量

### P3.1 直接法方法学
- 严格 CUEP：完整 BCU(exit point→gradient system→CUEP)、shadowing、controlling UEP。
- 能量函数：数值能量函数(处理转移电导的非保守性)、阻尼能量法(DEA)。
- 稳定域：更严格的稳定流形/Lyapunov 估计、SOS/凸优化 ROA。

### P3.2 软件工程
- **测试**：pytest 单元测试(现仅 1 个 smoke)+ 不变量测试 + 数值快照回归。
- **质量门**：`ruff`(lint)+ `mypy`(类型)+ GitHub Actions CI(推送即跑测试)。
- **打包**：完善 `pyproject`，可 `pip install`，语义化版本。
- **配置化**：实验用 YAML/JSON 描述，结果落盘(npz/parquet)+ 参数指纹，保证可复现。
- **性能**：缓存 `static`、向量化、参数扫描并行(`joblib`/multiprocessing)。
- **文档**：mkdocs/sphinx API 文档 + 示例 notebook。

### P3.3 可视化与结果管理
- 交互式 3D 稳定域(plotly，可旋转)；论文级样式(稳定域着色/透明曲面)。
- 统一结果对象 + 实验台账(每次跑什么参数、得什么结果，可回溯)。

## 推荐的下一步三件事(性价比最高)

1. **P0.1 的 T1 不变量 + 等面积 SMIB 解析 + scipy 交叉**——zero-MATLAB，立刻拿可信度。
2. **P0.2 修 5 个隐患**——消除"跨模式共用 static 出错""CCT=0"这类地雷。

IBR(P2.4)才踏实。

## 迁移策略

- `python_bcu/`(v1)**只读冻结**，作为对照基线与回归目标。
- `python_bcu_v2/` 起步可**复用 v1 的包**(`import bcu_3m9b`)，只新增 `validation/`、
  `solvers/`(scipy 封装)、`models/`(分级模型)等增量模块；稳定后再决定是否整体升级。
- 每一步改动都用 P0.1 的验证套件把关，确保"改进不破坏已验证的行为"。
